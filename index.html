COMPONENTES IDENTIFICADOS NO PROJETO

Infraestrutura e software

Informação confirmada pela configuração e pelos scripts existentes no repositório. Não representa uma leitura automática de versões instaladas.

INFRAESTRUTURA

Microsoft Azure VM

Máquina virtual gerida pela Azure. O painel consulta o estado de energia através do Azure Resource Manager.

SISTEMA

Linux · APT · systemd

Os scripts usam apt-get e systemd. A distribuição e a versão exatas do sistema operativo não estão identificadas no painel.

CONTENTORIZAÇÃO

Docker

O serviço Docker é verificado e o contentor do jogo é identificado pelo nome mc-server.

SERVIDOR DE JOGO

Minecraft

O contentor é consultado através de rcon-cli. A versão, a imagem Docker, o tipo de servidor e os mods/plugins não são publicados pelo estado atual.

GESTÃO REMOTA

SSH · Azure Run Command

A verificação tenta primeiro SSH e usa Azure Run Command como alternativa para consultar Docker e jogadores.

AGENTE PRIVADO

Python 3 · Cloudflare Tunnel

O repositório inclui um agente Python local na porta 8765 e um workflow para instalar cloudflared. A instalação ativa não é confirmada pelo painel.
